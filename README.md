# 🎓 AI-Powered Study Buddy

An AI-powered learning assistant built using Streamlit and Google Gemini API to help students study better.

---

## 🚀 Features
- Explain topics in simple language
- Summarize study notes
- Generate quiz questions
- Create flashcards
- Interactive web interface

---

## 🛠️ Tech Stack
- Python
- Streamlit
- Google Gemini API
- Git & GitHub

---

## ▶️ How to Run the Project

1. Clone the repository:
   git clone https://github.com/Abhinavsk4564/ai-powered-study-buddy.git

2. Install dependencies:
   pip install streamlit google-generativeai

3. Set Gemini API Key:
   setx GOOGLE_API_KEY "your_api_key_here"

4. Run the app:
   python -m streamlit run app.py
